Step 5: Manual Cache Clear (If needed)

If the automatic clear doesn't work, do this manually:

  1. Press F12 to open Developer Tools
  2. Go to the Application tab (or Storage in Firefox)
  3. In the left sidebar, find Local Storage
  4. Click on http://localhost:3001
  5. Select all entries and delete them
  6. Also clear Session Storage the same way
  7. Close Developer Tools and refresh the settings page
